# Klyro

Klyro is an online competitive gaming-cum-coding platform where developers form teams, compete in software-building battles, submit GitHub repositories, and receive AI-assisted evaluation, XP, ratings, and leaderboard rankings.

## Core Loop

ENTER → MATCH → TEAM UP → BATTLE → BUILD → SUBMIT → GET JUDGED → SCORE → RANK → LEVEL UP → BATTLE AGAIN

## Architecture

- Frontend: React + Vite + Tailwind
- Backend: Node.js + Express
- AI Service: Python + FastAPI
- Database/Auth: Supabase
- GitHub: GitHub REST API
- AI: Gemini or Claude
- Frontend Deployment: Vercel
- Backend Deployment: Render
- AI Service Deployment: Render

## Repository Structure

- `/frontend` — Frontend application
- `/backend` — Main backend
- `/ai-service` — AI/GitHub evaluation service
- `/database` — Database scripts
- `/docs` — Project documentation
- `/.github` — GitHub workflows and templates
